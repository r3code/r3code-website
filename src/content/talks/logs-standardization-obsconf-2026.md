## О докладе

Доклад о построении единого пайплайна логирования на открытом стеке — **Vector + OpenTelemetry + ClickHouse**.

Рассматривается миграция с EFK, схема источников (агент / daemonset + Kafka + ClickStack), разделение логов по явному TTL и пост-анализ бизнес-ошибок через Vector remap.

Особое внимание — стандартизации: единые имена сервисов по OTel Semantic Conventions, готовность телеметрии для MCP и AI-анализа.
